A browser that shows its work.

SpacePenguin is a small Qt and QtWebEngine browser. It keeps the parts you actually use — tabs, private windows, find in page, zoom, session restore — and adds a light and dark theme, user script extensions, content blocking, and honest about: pages. It is pre-alpha software, and it says so.

Build it yourself Read the limits first

Features

Light and dark

Pick Follow system, Light or Dark in View → Theme. The choice is saved. SpacePenguin sets the application colour scheme, and websites that honour prefers-color-scheme follow along. Websites that ignore it are still websites, so SpacePenguin does not rewrite their CSS.

Extensions, as user scripts

QtWebEngine does not support Chrome extensions, and SpacePenguin does not pretend otherwise. It runs JavaScript user scripts instead. Drop a .js file into the extensions folder, or use Tools → Extensions… to add one, then enable, disable or remove it.

// @name Readability helper
// @match *://example.com/*
console.log('running on', location.hostname);

A script with no // @match lines runs on every page. With // @match lines it runs only where the pattern matches the hostname.

Content blocking

SpacePenguin reads an Adblock Plus format filter list and applies it two ways: requests are blocked before they leave the browser, and ## element-hiding rules are compiled into a stylesheet injected at document creation.

Both halves matter. YouTube serves its ad requests from www.youtube.com itself, so a network rule can only reach the ad endpoints. The ad you actually see, the overlay and the pop-out player are elements in the page, and only element hiding touches those.

||googlesyndication.com^$third-party
||youtube.com/pagead/
/api/stats/ads?
youtube.com##.ytp-ad-overlay

A fresh install writes a small starter list so blocking is visible immediately. For real coverage point the browser at EasyList or another maintained list: --filter-list ./easylist.txt. SpacePenguin parses 53,859 network rules and 24,009 cosmetic rules from EasyList.

Click the blocking control in the status bar to turn blocking off, pause it for the site you are on, or check how many requests have been stopped.

Everyday browsing

Tabs and tab groups, an omnibox that resolves URLs and searches, back and forward, reload and stop, zoom, find in page with match highlighting, a progress bar, a security indicator, private windows that write nothing to disk, session restore, and multiple profiles.

Build

SpacePenguin needs Qt 6.4 or newer with QtWebEngine, CMake 3.21+, and a C++20 compiler.

cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build

On Nix, the exact set used for development:

nix-shell -p 'qt6.qtbase' 'qt6.qtdeclarative' 'qt6.qtwebengine' \
         cmake gnumake libglvnd

The build produces spacepenguin, a macOS app bundle, and a Windows GUI executable, plus four unit test binaries wired into CTest.

Using it

Command line

spacepenguin                          # normal window
spacepenguin --private                # nothing is written to disk
spacepenguin --user-data-dir ./profile # keep data somewhere else
spacepenguin --filter-list ./filters.txt

Where your data lives

Profiles, the bundled sp:// start page, the extensions folder and the default filter list live under the platform application data directory (~/.local/share/SpacePenguin on Linux). Private windows keep nothing.

Limits, stated plainly

  • Pre-alpha. No stability or compatibility promise. Save your work.
  • No Chrome extensions. QtWebEngine cannot load them. User scripts are the supported path.
  • Blocking is not complete. No $redirect or $removeparam rewrites, no ##+js() scriptlets, no per-site exception editor. A few sites still show placeholders or count blocked requests.
  • Pop-ups. Real pop-up windows are already refused by the security policy. In-page pop-ups and overlays need ## rules from your list.
  • Some sites will not work. Google sign-in, DRM playback and other services that depend on unsupported Chromium integrations commonly break in QtWebEngine.
  • The theme is application chrome. Page colours follow the site's own CSS.
