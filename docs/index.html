The browser that
stays out of your way.

SpacePenguin is a small, fast browser built on Qt and Chromium. It blocks ads and trackers — YouTube's included — skips sponsor segments, and runs the same on Windows, macOS, Linux and school Chromebooks.

Download View on GitHub

Free and open source · GPLv3 · Pre-release software

What you get

🛡️

Ads blocked, YouTube too

Ad networks and trackers are stopped before they load. On YouTube the ad schedule is taken out of the player's own data, so videos start without the ad — and an ad that slips through is muted and skipped.

⏭️

Sponsor segments skipped

Sponsor reads, self-promotion and "subscribe" reminders inside videos are skipped with SponsorBlock's community timestamps — without telling anyone which video you watch.

🪟

One clean row

Tabs and the window buttons share a single row; everything is rounded, from the tabs to the window's corners. Light, dark, or follow your system.

🔒

Private windows

A private window writes nothing to disk — no history, cookies or cache — and forgets everything when it closes.

💻

Light on small machines

On 4 GB laptops and Chromebooks it shares processes between tabs and switches on Chromium's low-end mode by itself. The window is up in about a third of a second.

🧩

User-script extensions

Drop a JavaScript file into the extensions folder and it runs on the sites you choose. Simple, inspectable, no store required.

🧱

Sandboxed, and honest about it

Pages run in Chromium's sandbox. If your system blocks it, SpacePenguin tells you why and how to fix it, instead of crashing or staying quiet.

📖

Pages that explain themselves

about:version shows what the browser is doing: the sandbox, the blocker, how it tuned itself for your device. about: pages cover history, downloads and more.

Which Linux package should I use?
  • AppImage — any distribution from Ubuntu 22.04, Debian 12 and Fedora 36 on (ARM64: Ubuntu 24.04, Debian 13 and newer). For faster starts, install it once: bash packaging/chromeos/install.sh SpacePenguin-*.AppImage.
  • .deb / .rpm — Debian 13, Ubuntu 25.04+, Fedora 41+, openSUSE Tumbleweed. They also set up the sandbox permission on Ubuntu.
  • Arch — packaging/arch/PKGBUILD.
  • Nix — nix run github:developer1-vd/SpacePenguin.
  • Flatpak — built from packaging/flatpak/.

On a school Chromebook

SpacePenguin runs in ChromeOS's Linux environment, on Intel, AMD and ARM Chromebooks, and tunes itself for 4 GB machines without GPU acceleration.

  1. Turn on Linux: Settings › About ChromeOS › Developers › Linux development environment.
  2. In the Terminal app, run the two lines on the right.
  3. Open it from the launcher, under Linux apps.

On a school-managed Chromebook, the school decides whether Linux is allowed. If the setting is missing or greyed out, only the school's admin can turn it on — there is no way around that from the Chromebook.

# download the installer, then run it
curl -fsSLO https://raw.githubusercontent.com/developer1-vd/SpacePenguin/main/packaging/chromeos/install.sh
bash install.sh

The installer needs a published release. It checks each download's SHA-256 and won't install a file that doesn't match.

Privacy, plainly

SpacePenguin has no account, no telemetry and no update pings. Apart from the sites you visit, it contacts only:

  • Your search engine, when you search from the address bar.
  • SponsorBlock, for skipping sponsor segments on YouTube. It's asked about only the first four characters of a hash of the video's ID — a prefix shared by dozens of videos, so it can't tell which one you're watching. You can turn it off in Settings.

Where your data lives

History, bookmarks and settings stay on your computer:

  • Linux: ~/.local/share/SpacePenguin/SpacePenguin
  • macOS: ~/Library/Application Support/SpacePenguin/SpacePenguin
  • Windows: %APPDATA%\SpacePenguin\SpacePenguin

Private windows keep nothing at all.

Build it yourself

One script installs everything — compiler, CMake and Qt 6.8 with QtWebEngine — on Debian, Ubuntu, Fedora, openSUSE, Arch, Alpine, Void, Gentoo, macOS and Windows.

Linux and macOS

git clone https://github.com/developer1-vd/SpacePenguin
cd SpacePenguin
./install-deps.sh
cmake -B build
cmake --build build --parallel "$(tools/build-jobs.sh)"
./build/SpacePenguin

Windows (PowerShell)

git clone https://github.com/developer1-vd/SpacePenguin
cd SpacePenguin
powershell -ExecutionPolicy Bypass -File install-deps.ps1
cmake -B build
cmake --build build --config Release --parallel 2

tools/build-jobs.sh runs only as many compiler jobs as your free memory allows — each needs about 500 MB, and running too many at once can freeze a small laptop. Packaging scripts for the AppImage, DMG and Windows installer are described in BUILD_SCRIPTS.md.

Good to know

It's pre-release

SpacePenguin is young. Expect rough edges, and please report what you find.

No Chrome Web Store

QtWebEngine can't run Chrome extensions, so SpacePenguin uses JavaScript user scripts instead — and has the blocker built in.

Chromium underneath

Pages render with Chromium through Qt's QtWebEngine, so sites work as they do in Chrome. Security updates follow Qt's releases.

YouTube changes things

YouTube changes how it delivers ads now and then. If an ad gets through, open an issue.
